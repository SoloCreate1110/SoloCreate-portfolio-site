# Catalog artwork

Generated with the built-in image generation tool on 2026-09-28, then exported as 1200 × 800 JPEGs for the website.

- `mayottara-gacha.jpg`: New illustration of an orange capsule machine and colorful capsules, with a warm cream backdrop and open space at the left.
- `void-bloom.jpg`: Space illustration based on `games/void-bloom/assets/earth-source.png`, preserving its pixel-art Earth style with a star field and small enemy spacecraft.

Full generation prompts are in `prompts.txt`. Fades are applied in CSS so the artwork reaches the card edges without baked-in white borders.
