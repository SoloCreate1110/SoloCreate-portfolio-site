# まよったらガチャ

## 目的
日常の小さな選択を、候補から気軽に決める。スマートフォンとPCで使えるローカル保存のアプリ。

## 今回採用した機能
- 毎回ランダム：全候補から等確率で独立抽選。Web Cryptoの32bit乱数に棄却法を適用し、剰余による偏りを避ける。
- 一巡まで重複なし：残っている候補から等確率で抽選し、一巡後に全候補へ戻す。巡回の境界では連続して同じ結果になる場合がある。
- 各候補の「次の抽選」の確率と選出済み状態を表示。
- 履歴100件、出現回数、抽選モードの記録。画面では最初に10件を表示し、残りを展開できる。
- 複数ガチャの作成・編集・削除。改行区切りで候補をまとめて入力。
- 名前32文字、候補2〜100個、各40文字。空行を除外し、NFKC正規化・大小文字を無視した同名候補を拒否。
- JSONバックアップと復元（5MBまで）。復元前に検証と置換確認を実施。
- 音・振動設定、動きを減らすOS設定への対応、キーボードフォーカスと結果読み上げ。

## データと互換性
- localStorageキー `mayottara-gacha:v1` を維持。旧データの抽選モード省略時は毎回ランダム。
- 結果・履歴・残り候補を一度に保存してから演出。保存が失敗したらキャッシュも更新しない。
- 壊れた既存データを自動初期化しない。
- 編集時は同名候補のIDと履歴を維持し、重複なしの巡回をリセット。
- 履歴の出現回数は保存中の100件のみ。候補編集前の履歴も残す。

## UIと構成
TypeScript + Vite + HTML/CSS。固定位置のCanvas表示を廃し、通常の文書レイアウトでスクロール・長文・画面幅変更に対応。白とグリーンを基調としたカード一覧、結果を一か所に集約した抽選画面。

## 今回見送った機能
重み付き抽選、アカウント、クラウド同期、画像付き候補、共有URL。日常の即決という目的に対して設定や管理が増えるため、今回は導入しない。

## 検証
- `npm test`：抽選の境界値・棄却、独立抽選での連続一致、100巡の重複なし、旧形式とID維持、入力検証、履歴上限、保存失敗、バックアップ。
- `npm run build`：TypeScriptチェックとViteビルド。
- Safari：一覧・作成・抽選・モード切替・確率更新、390pxのレスポンシブ画面を確認。

## 確率の説明
4候補の独立抽選で、あらかじめ区切った5回がすべて同じになる確率は `(1/4)^4 = 1/256`（約0.39%）。多数回引いたときに、どこかで5連続が起きる確率とは異なる。

## 2026-10-01 操作・抽選演出の改善

一覧の「すぐ引く」、前回結果保持、結果コピー、3種ひな形、複製編集を追加。CSSのカプセル演出は900msで、スキップ・OS/アプリ内の動き軽減に対応。URLで画面を保持し、戻る・再読み込みと未保存編集の確認を実装。削除・履歴消去は直後の通知で取消でき、画面移動や次の変更で取消期間が終わる。結果の保存を演出前に完了し、演出中の画面移動でも抽選は失われない。結果直後650msとダブルクリック・キー押しっぱなしの誤連打を抑制。

任意の設定 `reducedMotion` を追加し、v1キーと既存バックアップを維持。検証はBraveのPC/768/390/320px、build・型チェック、17件の単体テスト。連続抽選・スキップ・連打・動き軽減・抽選中の移動、任意削除・キャンセル・Escape・取消・保存再読み込み・最後の1件の削除と空一覧からの作成を確認。既存ユーザーの保存データを消去せず、専用のテスト保存領域で操作を検証。

再抽選は表示専用の closed/closing/drawing/revealed 状態で毎回閉じてから開く。演出タイマーを移動・スキップ時に取り消し、抽選処理と分離。任意ガチャを一覧カードまたは編集画面から削除でき、対象名を示す確認ダイアログ・Escape・直後の取消を提供。480px以下の一覧は操作の読みやすさを優先した1列。
