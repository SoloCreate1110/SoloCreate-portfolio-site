# 進化武器のビジュアル更新 — v36

6武器の通常形態と、全12種類の進化先を専用の形状で描画。色だけでなく、弾の輪郭・尾・発射口・着弾・衛星本体を変えた。

| 武器 | 進化 A | 進化 B |
| --- | --- | --- |
| パルス | 装甲とフィンのある緑のエネルギー弾 | 長い穂先と衝撃輪を伴うスナイパー弾 |
| 拡散 | 扇状に広がる幅広い金色の刃 | 細長い金色の貫通弾 |
| レーザー | 3本の光柱と発射リング | 太い光柱・二重リング・流れる発光模様 |
| ミサイル | フィンと長い噴射尾を持つ追尾ミサイル群 | 側面装甲・補助噴射器を持つ大型弾、広がる多重衝撃波 |
| 雷撃 | 枝分かれする連鎖雷撃と着弾閃光 | 太い雷撃・分岐放電・大きな着弾閃光 |
| オービタル | 翼型の衛星と翼型弾 | 重装甲の衛星と幅広い砲弾、分割防御リング |

## バランスと視認性

- ダメージ、連射間隔、弾数、当たり判定、爆風判定、相殺ルールはv35を維持。
- 敵弾と危険範囲、自機の当たり判定を味方のエフェクトより後に描画。
- 爆風の面塗りは薄くし、中心付近の敵弾が見えるようにした。
- 発射済みの弾は発射時の外観を保持する。

## 軽量化

- 弾や衛星の発光は小さなCanvasへ一度描画して再利用。弾の角度ごとの画像は生成しない。
- 爆風は8段階の画像を再利用。キャッシュ全体の上限512枚を維持。
- 新しい装飾用の着弾・発射演出は、エフェクト数96以上では追加しない。ゲーム判定を持つビーム・雷撃は制限しない。
- 武器のリアルタイム描画ではぼかし処理を使わない。動きを減らすOS設定にも対応。
