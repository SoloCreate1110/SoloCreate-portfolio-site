# 2026-09-22 実装・検証記録

## スマホ操作修正
- `innerHTML` 再生成でボタン要素が入れ替わるのに、DOMキャッシュが古い `reroll` / `banish` を返していた。動的ボタンは毎回現在のDOMを取得する。
- メニュー生成後350msは選択を受理せず、新しいpointerdownを要求。メニュー前から継続したタッチは時間経過だけでは有効化しない。キーボードも350msを適用。
- スマホ・狭い画面の低速ボタンはトグル。PC Spaceは従来のホールド操作。相対ドラッグは維持。

## 特別コア
ボス後に重複なしのランダム3択。通常レベルアップとは別。全6種：
- 限界出力炉：威力+35% / 最大HP-25。
- 飽和射撃：発射頻度+50% / 単発威力-20%。
- 狙撃姿勢：低速中威力+60% / 通常時-10%。
- サルベージ契約：経験値+40% / 被ダメージ+20%。
- 緊急放電：被弾時半径160に80ダメージ / 被弾後無敵0.8秒。
- 再生装甲：5秒ごとHP3回復 / 威力-10%。

## 敵・ステージ
W1-4地球低軌道、W5-8月面航路、W9-12侵略艦隊宙域。背景に月・艦隊シルエットを追加、後半ほど特殊敵・新ランナー比率増加。地球と母艦は維持。
W3以降の通常ウェーブは通常／小型群／突進群から抽選。小型群は弱い高速雑魚と短い出現間隔。突進群は非射撃敵をジグザグ／予告突進に変更。敵数を無制限に増やさない。予告突進は1秒停止し、そのとき確定した方向へ突進する。

## 開発記録
通信・外部送信なし。localStorageに直近10出撃を保存。結果画面からJSONをダウンロード。`window.voidBloom.balance()` でも読める。
ボス到達時のレベル、武器、HP、到達時間、ウェーブ終了時の時間・被弾累計・進化・特別コア・武器別実ダメージ/撃破数を記録する。連携の追加ダメージは発生元武器に帰属。接触・特別コアのダメージは武器に加算しない。
