# 難易度と第3ボスの調整（v35）

出撃準備 → パイロット選択 → 戦闘。横スライダーは0〜100（1刻み）、初期25。右へ進むほど背景が暗い赤に変わり、倍率を即時表示する。設定は出撃時に固定し、全12ウェーブに適用。25を超える難易度の敵数・攻撃の増加分は序盤に抑え、後半ほど強くする。敵HPは全ウェーブで設定倍率をそのまま適用。同じキャラで再出撃すると設定を維持。結果画面から設定し直せる。ページ再読み込みで25に戻る。

倍率表はW11以降の到達値。序盤の実効倍率は下記の緩和を適用する。

| 設定 | 0 / EASY | 25 / NORMAL | 100 / HELL |
|---|---:|---:|---:|
| 編成の敵数 | 0.65倍 | 1倍 | 2倍 |
| 敵・ボスHP | 0.55倍 | 1倍 | 4倍 |
| 発射頻度 | 0.65倍 | 1倍 | 1.85倍 |
| 敵弾速度 | 0.8倍 | 1倍 | 1.45倍 |
| 被ダメージ | 0.65倍 | 1倍 | 1.8倍 |
| 編成到着頻度 | 0.8倍 | 1倍 | 1.35倍 |

0〜25は線形、25〜100は正規化値の1.25乗で補間。敵数とHPは整数丸め、編成は最低2体。序盤専用HPにも設定した耐久倍率をそのまま適用。数を無制限に増やさず、耐久・弾速・射撃で難度を上げる。予告時間・移動速度・経験値単価は維持。白範囲攻撃は難易度によらずHP全損（無敵中は無効）。難易度はポーズ・結果・開発記録にも表示・保存。

## 第3ボス

- 両形態とも橙弾ゼロ。通常弾は赤、紫は引き続き8回ごとの特別射撃。
- 主攻撃は回転弾幕とレーザーを交互に使用。通常間隔は第一形態0.9秒、第二形態0.55秒。
- レーザー後の回復を3秒から0.2秒に短縮。
- 独立した赤弾3発の狙い撃ちを第一形態0.8秒、第二形態0.55秒ごとに実行。予告・発動・回復・白攻撃中も継続。
- 3本／4本の固定レーザー、2秒／1.65秒の予告、退避通路を維持。白範囲と赤レーザーは重ねない。

## 検証

- `tests/game.test.cjs`：既存12ウェーブ・全武器・入力・衝突・ボス回帰。両形態16攻撃で橙ゼロ、退避通路、射撃継続を追加検証。
- NORMALの各形態60秒検証：最大射撃間隔0.78秒／0.67秒、レーザー17回／22回（白攻撃待機を長くした条件）。
- HELLの各形態120秒検証：弾数ピーク41発／56発。白攻撃を含む攻撃継続、範囲攻撃数、撃破時の解除を確認。無敵・無攻撃の検証用プレイヤーであり、クリア難度の実プレイ計測ではない。
- `tests/expansion.test.cjs`：101段階の単調増加、初期位置、DOM再生成後の操作、開始時固定、敵編成・序盤HP・ボスHP・弾速・被ダメージ・記録への適用。
- `tests/performance.test.cjs`：衝突候補・HUD差分・発光キャッシュの既存検証を通過。
- Safari：PC、375×667、320×568のレスポンシブ表示。スライダー操作・色／数値更新・キャラ選択・開始・ポーズで設定を確認。小型画面も準備画面が収まるよう余白調整。

## v34：序盤の緩和と中型敵

- 難易度25を超える増加分に、W1〜12で8 / 16 / 28 / 38 / 52 / 62 / 72 / 80 / 90 / 96 / 100 / 100%を適用。敵数・HP・射撃頻度・弾速・被ダメージ・編成到着頻度が対象。EASY側の軽減は全ウェーブ維持。
- HELLのW1は8体×5組→4体×5組、HP12→4。敵数・HPを同時に急増させない。W1は非射撃、W2は中型敵なし、W3は砲台1体までの導入を維持。
- W5以降、後続編成の雑魚の一部を砲台・レーザー狙撃機・ワープ爆撃機に置き換え。追加は1編成1体まで。
- NORMALで予定される中型敵はW5：3→4体、W6〜7：4→6体、W9〜11：5→8体。HELLはW5：5体、W6〜7：7体、W9〜10：10体、W11：11体。生存数が上限に達している場合は通常敵に戻す。
- 中型敵の同時生存上限はW3が1体、W5〜7が4体、W9以降が6〜8体。範囲攻撃の既存同時上限2つ・予告時間を維持。
- 開始通知とフィールド上部を `WAVE 01` など番号のみの表示に統一。ボス固有名はボスHP表示に残す。
- `tests/difficulty-pacing.test.cjs`：全101段階でW1が1組4体以下・HP4以下。難度上昇、各編成、中型敵数・上限、全12ウェーブの短い表示を検証。
- 同テストの実移動・実射撃によるW1検証（照準を合わせる簡単な自動操作。無敵化・敵HP変更・直接撃破なし）：NORMAL/HELLとも3キャラ全員が復活未使用でW2へ到達、Lv.3。HELLでAEGIS/LANCERは20撃破、SERAPHは17撃破。人間のクリア率を保証する検証ではない。
- 既存ゲーム回帰・拡張機能・描画性能テストも通過。Safariで出撃準備の説明とWAVE番号のみの実画面表示を確認。

## v35：敵の耐久倍率を戻す

- 敵HPだけ段階的な緩和から除外し、v33の耐久に戻した。雑魚・中型敵・ボスが対象。
- HELLのW1はHP4→12。編成は4体×5組のまま。敵数・攻撃・被ダメージの緩和、中型敵の追加と上限、WAVE番号のみの表示を維持。
- 難易度画面は耐久が「全WAVE」に適用されることを明記。
- 全101段階でW1のHPが設定倍率と一致すること、各ウェーブのボスHP、編成の維持、既存ゲーム・拡張機能の回帰テストを確認。
- 無敵化なしの自動照準・通常移動によるW1検証：HELLでも3キャラとも復活未使用でW2へ到達。AEGIS 19撃破/Lv.3、LANCER 20撃破/Lv.3、SERAPH 10撃破/Lv.2。人間のクリア率を示すものではない。
