# 難易度と第3ボスの調整（v33）

出撃準備 → パイロット選択 → 戦闘。横スライダーは0〜100（1刻み）、初期25。右へ進むほど背景が暗い赤に変わり、倍率を即時表示する。設定は出撃時に固定し、全12ウェーブに適用。同じキャラで再出撃すると設定を維持。結果画面から設定し直せる。ページ再読み込みで25に戻る。

| 設定 | 0 / EASY | 25 / NORMAL | 100 / HELL |
|---|---:|---:|---:|
| 編成の敵数 | 0.65倍 | 1倍 | 2倍 |
| 敵・ボスHP | 0.55倍 | 1倍 | 4倍 |
| 発射頻度 | 0.65倍 | 1倍 | 1.85倍 |
| 敵弾速度 | 0.8倍 | 1倍 | 1.45倍 |
| 被ダメージ | 0.65倍 | 1倍 | 1.8倍 |
| 編成到着頻度 | 0.8倍 | 1倍 | 1.35倍 |

0〜25は線形、25〜100は正規化値の1.25乗で補間。敵数とHPは整数丸め、編成は最低2体。序盤専用HPにも倍率を適用。数を無制限に増やさず、耐久・弾速・射撃で難度を上げる。予告時間・移動速度・経験値単価は維持。白範囲攻撃は難易度によらずHP全損（無敵中は無効）。難易度はポーズ・結果・開発記録にも表示・保存。

## 第3ボス

- 両形態とも橙弾ゼロ。通常弾は赤、紫は引き続き8回ごとの特別射撃。
- 主攻撃は回転弾幕とレーザーを交互に使用。通常間隔は第一形態0.9秒、第二形態0.55秒。
- レーザー後の回復を3秒から0.2秒に短縮。
- 独立した赤弾3発の狙い撃ちを第一形態0.8秒、第二形態0.55秒ごとに実行。予告・発動・回復・白攻撃中も継続。
- 3本／4本の固定レーザー、2秒／1.65秒の予告、退避通路を維持。白範囲と赤レーザーは重ねない。

## 検証

- `tests/game.test.cjs`：既存12ウェーブ・全武器・入力・衝突・ボス回帰。両形態16攻撃で橙ゼロ、退避通路、射撃継続を追加検証。
- NORMALの各形態60秒検証：最大射撃間隔0.78秒／0.67秒、レーザー17回／22回（白攻撃待機を長くした条件）。
- HELLの各形態120秒検証：弾数ピーク41発／56発。白攻撃を含む攻撃継続、範囲攻撃数、撃破時の解除を確認。無敵・無攻撃の検証用プレイヤーであり、クリア難度の実プレイ計測ではない。
- `tests/expansion.test.cjs`：101段階の単調増加、初期位置、DOM再生成後の操作、開始時固定、敵編成・序盤HP・ボスHP・弾速・被ダメージ・記録への適用。
- `tests/performance.test.cjs`：衝突候補・HUD差分・発光キャッシュの既存検証を通過。
- Safari：PC、375×667、320×568のレスポンシブ表示。スライダー操作・色／数値更新・キャラ選択・開始・ポーズで設定を確認。小型画面も準備画面が収まるよう余白調整。
